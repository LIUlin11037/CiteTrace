# Backlog：表格页检索失败（A 类问题）

> 状态：**不进本期**（本期冻结在"只调检索参数"）
> 触发依据：Stage A 实测，`api + p50 + exp3` 配置下 21 题中 2 题完全未召回，
> **且两题都指向同一页** —— AMEX 2022 10-K 第 96 页（合并利润表）。

---

## 1. 问题（已核实的版本）

> 本节经过二次核实：初版结论「4000 字符截断导致内容丢失」「2 题同页全部失联是数据问题」
> **均被推翻**，下面是验证后的版本。

**核实方法**：拿官方 `evidence_text` 的前 40 字（去空白）在整份文档的所有块里做精确匹配。

结果：

| 状态 | 题数 | 说明 |
|---|---|---|
| 答案在索引内 | **20 / 21** | 数据完整，检索层理论上限 95% |
| 答案不在索引内 | 1（financebench_id_00476） | AMEX 首页，证据文本跨块被打散 |

**也就是说：检索失败几乎全部是排序/匹配问题，不是数据缺失。**

### 三类可复现的失败

**A 类 · 数字密集页排不进前 50（2 题）**

```
financebench_id_00720 / 00723  →  AMEX p96（合并利润表，2199 字符）
答案文本确实在 p96 块内，但用尽 embed + rerank + 扩展仍进不了前 50。
```

同一页两题全灭 → 不是随机噪声，是**该类页面的表征不可检索**：
页面是"标签 + 30 个指标 × 3 个年度"的数字流，query 与其几乎没有共享语义。

**B 类 · 排序回归（5 题，本阶段最意外的发现）**

从基线（api 无 rerank 无扩展）到最优配置（api + rerank50 + 扩展3）：

```
新进 top10：10 题
掉出 top10：5 题   ← 00464 (3→14) 00476 (1→44) 01198 (2→44) 01290 (3→16) 01981 (8→44)
净收益：+5 题（8/21 → 13/21）
```

**平均指标掩盖了 5 题被"优化"弄坏**。这正是需要 paired 分析与"不显著变差"门禁的原因。

**C 类 · 数据缺失（1 题）**

`00476` 的证据来自 AMEX 首页（p1 共 250 + 4000 两块），文本被拆散后无法匹配。
属于**抽取层问题**，与检索参数无关。

### 一个被排除的假设

`kb_chunks_qwen` 有 706 块 / 570 个唯一页 —— 136 个"重复"是**长页按 4000 字符拆块**
（4000 + 尾块，锚点同为该页），不是截断，也没有内容丢失。

实测同页多块对 top-10 的影响可忽略：抽样 6 题，top-10 平均覆盖 **9.8/10** 个不同页。

## 3. 方案（按成本排序）

### 方案 A（推荐）：页级 + 行级双写

```
页级块（保留）：保持不变，负责引用锚点
行级块（新增）：每行 = 表头 + 标签 + 该行数值，anchor 仍写同一页
```

例：

```json
{
  "text": "[CONSOLIDATED STATEMENTS OF INCOME | Millions | 2022 2021 2020] Discount revenue: 2022=3,142 / 2021=2,708 / 2020=2,116",
  "source_path": "AMERICANEXPRESS_2022_10K.pdf",
  "anchor": "p96",
  "chunk_type": "table_row"
}
```

**优点**：不动引用核验（anchor 仍是 p96），只多写一份索引。
**代价**：索引膨胀（706 → 约 3000–7000 块），检索延迟上升。

### 方案 B：表格结构化抽取

`pdfplumber` 抽表 → 转 Markdown → 单独索引。
**问题**：已实测负收益（57%→14%），噪声大。

### 方案 C：表格页路由

先判别"表格页"（数字字符占比 > 30%），命中时切换检索策略（标签模糊 + 数值匹配）。
**问题**：要写两条检索路径，复杂度最高。

## 4. 为什么现在不做

本期冻结范围是「只调检索参数」，改切块会牵动：

```
ingest_kb.py（切块逻辑）
→ 索引结构（新增 chunk_type 字段）
→ 全部 12 组 Stage A 实验需重跑
→ 引用核验要确认行级块不会破坏页码锚点
```

**一旦开了这个口，本期实验的结论就没法归因了**（参数变化 vs 切块变化混在一起）。

## 5. 预估收益与成本

| 项 | 估计 |
