> 所有条目都有落盘数据支撑，可按 `qid` 复现。
> 配套数据：`experiments/stageA_raw.csv`、`experiments/stageB_compare.json`

## 总览

| 类 | 名称 | 数量 | 出现层面 | 可调参解决 |
|---|---|---|---|---|
| A | 数字密集页排不进前 50 | 2 | 检索 | ❌ 需改切块 |

## A 类 · 数字密集页排不进前 50（2 题）

```
financebench_id_00720 / 00723  →  AMEX 2022 10-K p96（合并利润表，2199 字符）
```

**已验证**：官方 `evidence_text` 确实在 p96 的块内（精确匹配通过）。
但用尽 api embedding + rerank + 扩展，仍进不了前 50。

**根因**：该页是「标签 + 30 个指标 × 3 个年度」的数字流。
query（自然语言问句）与页内文本几乎没有共享语义单元，向量相似度天然低；
字面匹配也无效，因为页内是 `50,680` 这样的纯数字。

**修法**：行级切块 + 表头拼接，让 `Revenues | 2022 | 50,680` 成为独立检索单元。
**成本**：`ingest_kb.py` 约 80 行 + 索引膨胀 5–10 倍。
**状态**：backlog，见 `docs/backlog-表格页检索失效.md`。

## B 类 · 优化导致的排序回归（5 题）

从基线（api / 无 rerank / 无扩展）到最优（api / rerank50 / 扩展3）：

```
新进 top10：10 题
掉出 top10： 5 题
  00464   3 → 14
  00476   1 → 44
  01198   2 → 44
  01290   3 → 16
  01981   8 → 44
```

**这是本次实验最重要的发现**：hit@10 从 38.1% 升到 61.9%（+23.8 点），
但这个提升是「10 进 5 出」的净值，不是「10 题全都变好」。

**含义**：任何只看均值的调参，都会在不知情的情况下用 5 个失败换 10 个成功。
工程上必须做 paired 分析，并设「不显著变差」门禁。

**候选修法**（未验证）：
- rerank 前按 `anchor` 去重，避免同页多块互相竞争
- 融合时对 rerank 分数加原始排名先验，防止精排过度自信
- 对「原本排第 1–3 名」的块做保护（top-3 不参与重排）

## C 类 · 证据未入索引（1 题）

```
financebench_id_00476  →  AMEX 2022 10-K p1
```

**已验证**：官方 `evidence_text` 在整份文档的所有块里都找不到。

p1 是封面/目录页，被拆成 250 + 4000 两个字块，证据文本跨块后被打散，
去空白后无法精确匹配。

**修法**：抽取层保留原文换行与列结构，或对首页/目录页单独处理。
**影响**：4.8%（1/21），属抽取问题，与检索参数无关。

## D 类 · 空召回 → 报告无脚注（3 题，仅出现在无扩展配置）

```
fb-08 / fb-20 / fb-21
```

**因果链（已用落盘数据验证）**：

| 题 | 无扩展证据条数 | 有扩展证据条数 | 无扩展引用率 | 有扩展引用率 |
|---|---|---|---|---|
| fb-08 | **0** | 37 | 0% | 100% |
| fb-20 | **0** | 27 | 0% | 100% |
| fb-21 | **0** | 32 | 0% | 100% |

**机制**：单路检索对这些题返回 0 条可用证据 → Writer 无料可写 →
报告不生成任何脚注 → 引用存在率 0%、覆盖率 0–50%。
三路扩展后至少一路有结果（27–37 条），Writer 恢复引用生成。

**这是「检索为空」向「生成层」的传导失败**——不是引用造假，是根本没有引用。

**修法**：query 扩展（已验证有效）。
**附带建议**：检索为空时应显式降级（报告声明「未检索到相关证据」），
而不是静默生成一篇无脚注的报告——后者看起来像正常输出，危害更大。

## 统计口径（必须一起报）

```
n = 21  →  1 题 = 4.8 个百分点
配对 bootstrap（2000 次）：
  最优 vs 基线    +23.8%  [-9.5%, +57.1%]   不显著
  扩展 vs 扩池    +0.0%   [0%, 0%]          完全等价
  扩展（同池）    +9.5%   [-9.5%, +28.6%]   不显著
  候选池 50→100   +9.5%   [-9.5%, +28.6%]   不显著

McNemar 精确检验：10 胜 / 5 负 / 6 平 → p = 0.302，不显著
```

**结论措辞**：本实验提供的是**机制观察**（每个机制救回了哪些题、弄坏了哪些题），
不是**效果证明**（样本量不足以宣称显著）。

这个区分必须主动说出来——否则就是拿点估计冒充结论。
